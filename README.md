# Atividade Prática: Paradigma MapReduce

Repositório dedicado à implementação e estudo do paradigma **MapReduce**, contendo os códigos desenvolvidos para a atividade acadêmica.
Com o inutuito de entender o funcionamento e limitações do paradigma, limitou-se o uso de bibliotecas, principalmente a biblioteca pandas.

## Tecnologias Utilizadas
* **Python** / **Google Colab** (Ambiente de desenvolvimento e execução)
* **Git & GitHub** (Controle de versão e entrega do projeto)

---

## Estrutura do Repositório

O projeto está organizado da seguinte forma:
* `*.ipynb` — Notebooks contendo a implementação do algoritmo MapReduce, com um breve resumo do que é o MapReduce e explicações da lógica.

---

## Como Executar o Projeto

Como o código foi desenvolvido utilizando o Google Colab, você pode executá-lo de duas formas:

1. **Diretamente pelo Navegador:**
   * Clique no arquivo `.ipynb` correspondente dentro deste repositório.
   * Clique no botão **"Open in Colab"** (caso tenha a extensão) ou abra o [Google Colab](https://colab.research.google.com/), selecione a aba **GitHub** e cole o link deste repositório.

2. **Localmente:**
   * Clone o repositório na sua máquina:
     ```bash
     git clone [https://github.com/gustavomqv/atividade_MapReduce.git](https://github.com/gustavomqv/atividade_MapReduce.git)
     ```
   * Abra os arquivos utilizando o Jupyter Notebook ou Jupyter Lab.
